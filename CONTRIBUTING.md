# Contributing

`main` is protected. Only the owner, @abaaba337, pushes to it directly. Everyone else opens a pull request, and it merges once the owner has approved it. New commits after an approval need a fresh approval.

1. Fork the repository and make your change on a branch.
2. Run `python scripts/check.py`. It covers the leak guard, server tests, type check, build and browser tests.
3. Open a pull request that says what changed and why.

Never add student work to this repository, or anything that identifies a student: no PDFs, rosters, marks or names, in code, tests, fixtures, screenshots or commit messages. Tests use generated PDFs only.
